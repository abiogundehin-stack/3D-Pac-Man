🕹️ 3D Pac-Man Arcade: Admin & Owner Edition

A fully interactive, web-based 3D recreation of the classic Pac-Man arcade game built using Three.js, Tailwind CSS, and procedural Web Audio. Designed with built-in live customization engines, debug admin commands, and an infinite emote system.

✨ Features

🎮 3D Engine & Camera Angles: Rendered in real-time with Three.js featuring Isometric, Top-Down, and 3rd-Person Follow camera perspectives.

🔊 Procedural Audio Synthesizer: Pure Web Audio API sound effects for mouth chomps, power pellets, eating ghosts, emote triggers, and game-over sounds (no external audio files required).

🛡️ Admin Command Panel: Real-time cheats including Infinite Health (God Mode), Noclip, Hyper Speed Boost, Power Pellet Spawning, and Ghost Manipulators (Freeze/Spawn/Despawn).

⚙️ Owner Live Editor: Modify maze wall lighting/themes, Pac-Man scale, pellet score multipliers, ghost chase speeds, and custom power pellet durations during live gameplay.

🎭 Infinite Emote System: Interactive Emote Wheel featuring visual animations, particle aura trails, 3D floating text banner reactions, and customizable zero-cooldown toggles.

🛠️ Panel Capabilities

👑 Admin Panel ([A])

God Mode: Permanent immunity to ghost collisions.

Infinite Emotes: Removes all emote cooldowns and enables continuous particle trails.

Noclip / Ghost Mode: Pass freely through solid maze walls.

Entity Spawners: Instantly drop power pellets or force frightened chase modes.

Ghost Manipulator: Freeze all ghosts, spawn new colored ghosts, or wipe all ghosts off the map.

⚙️ Owner Editor ([O])

Theme Customizer: Neon Cyberpunk, Classic Blue Arcade, Sci-Fi Glow, Matrix Emerald, and Gold Luxury wall shaders.

Engine Sliders: Tweak Pac-Man scale, Pac-Man speed multiplier, ghost speed, power pellet duration, and point multipliers in real-time.

Level Controls: Auto-win current map level or instantly respawn all maze pellets.

🚀 Getting Started

Save the generated index.html file to your computer.

Open index.html in any modern Web Browser (Chrome, Edge, Firefox, Safari).

Use the keyboard shortcuts or HUD buttons to open panels, spawn items, or trigger infinite emotes!
